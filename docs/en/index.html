SecGeol

A tool for building and interpreting geological sections

Developed by Aura Ramos Lora

Before you begin

SecGeol is a QGIS tool that provides a workflow for building and modeling a subsurface geological interpretation from a section.

Before using the tool, it is recommended to first prepare a geological section project. This means loading into the map view the input data that may be used to construct the profile and correctly defining the project coordinate reference system.

Coordinate system. SecGeol works with projected coordinates and metric units. Therefore, using a UTM projection appropriate for the study area is recommended. Geographic coordinates expressed in degrees are not suitable for directly working with the distances required to construct the profile.

Workflow

SecGeol is organized into three consecutive phases, which take the workflow from the original spatial data to a three-dimensional representation of the geological interpretation.

1. From section to profile

In the first phase, the required input data are provided to generate a topographic profile along a section line.

This profile provides the framework for interpreting the subsurface geology, using the available information and your geological knowledge to sketch contacts, units, and structures.

2. From interpreted lines to polygons

Once the subsurface interpretation has been completed, the drawing is still essentially a set of lines. In this second phase, SecGeol transforms those lines into closed geological polygons.

The polygons can be identified using names, codes, or attributes corresponding to the different interpreted units or lithologies.

This phase produces the geological polygon profile, which can be used directly in maps, figures, and reports. The output also preserves a metric reference for the profile, with the corresponding distances along its horizontal axis.

3. 3D profile reconstruction

In the third phase, the polygons interpreted in the profile can be reconstructed in their real-world spatial position, using the section generated during the first phase as a reference.

The result is a geological profile with three-dimensional geometry, which can be visualized and analyzed in environments compatible with 3D data, such as the QGIS 3D view, ArcScene, or Leapfrog.

Output files. In all three phases, SecGeol generates vector layers that can be saved in Shapefile (*.shp) or GeoPackage (*.gpkg) format.

Input data for preparing the section project

Before you begin, load into QGIS the data you will use to construct the section. Not all inputs are required, but having more information available provides greater context for the interpretation.

1. Digital Elevation Model or contour lines

SecGeol requires an elevation source to construct the topographic profile. This can be a Digital Elevation Model (DEM) or a contour line layer.

The elevation source is one of the main inputs of the project and must use a projected coordinate system with metric units. It is recommended to use its coordinate reference system as the basis for maintaining spatial consistency among the data used throughout the procedure.

2. Section line

This is the line that defines the path along which the profile will be constructed.

An existing section from a line layer can be used, or the section can be drawn directly over the study area. Its path determines which terrain, geology, and structural information will be projected onto the profile.

3. Geology

If a geological polygon layer is available, it can be incorporated into the project.

When the section line crosses different geological units, their contacts can be transferred to the profile and used as a reference for the subsurface interpretation.

4. Structures

A geological structures layer can also be incorporated.

Structures that intersect the section line can be projected onto the resulting profile and used to support the geological interpretation.
